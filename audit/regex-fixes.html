OP 221

Apple TV+

missed service tagbug in v1 + v2

Changed 2026-08-07 04:20 UTC · op 221

The spelled-out form was a literal with a space (and the group's trailing anchor could not even close after "+."), so real dotted naming like Apple.TV+.WEB-DL and plus-less Apple.TV.WEB-DL never matched. The spelled form now takes a separator class and requires a following WEB token — same guard style as Max/iTunes/Movies Anywhere, and the same fix class as Paramount+ (OP 215).

\b(ATVP|ATV|APTV|Apple TV\+)\s*\b
\b(ATVP|ATV|APTV)\s*\b|\bApple[ ._-]?TV\+?(?=[ ._-]?WEB[ ._-]?(DL|RIP)?\b)

OP 219

Full Disc

was banning ordinary DVDRipsbug in v1 + v2

Changed 2026-08-06 20:15 UTC · op 219

The regex's trailing alternative sat outside its own rip-exclusion guard and used unanchored tokens, so ordinary PAL/NTSC DVDRips — whose DVD source the format's conditions don't exclude — took the −999999 full-disc ban, and PAL matched inside words like "Palm". The tail now carries its own rip/remux guard and word-bounded tokens. Codecs stay out of the guard on purpose: UHD discs are HEVC, and DVD9-sourced re-encodes are already rescued by the format's Not-x265 condition.

…|(?i)(DVD9|DVD5|NTSC|PAL|VOB IFO|VC-1|AVC|MPEG-2|\bCOMPLETE[-.\s]?(?:UHD[-.\s])?BLU[-.\s]?RAY\b|…)
…|(?i)^(?!.*\b(BDRip|BRRip|DVD[._ -]?Rip|WEB[._ -]?(DL|Rip)|XviD|((BD|UHD)[._ -]?)?Remux)\b).*\b(DVD9|DVD5|NTSC|PAL|VOB IFO|VC-1|AVC|MPEG-2|COMPLETE[-.\s]?(?:UHD[-.\s])?BLU[-.\s]?RAY|…)\b

OP 218

Extras (format wiring)

live ban never firedv2 only · v1 wiring was fine

Changed 2026-08-06 19:20 UTC · op 218

Same wiring bug as DUBBED, but live: Extras bans bonus-content releases at −999999 in 20 profile entries, yet required its movie condition (year anchor) AND its series condition (S## anchor) at once. Movie extras carry no season marker and TV extras packs usually no year — both classes sailed past the ban. Conditions are now either-or.

Movie Extras required · TV Extras required  (AND — needs year + S## together)
Movie Extras optional · TV Extras optional  (OR — either form fires)

OP 217

DUBBED (format wiring)

format could never matchv2 only · format absent in v1

Changed 2026-08-06 18:40 UTC · op 217

Not a regex bug: the format required its movie condition (year-anchored) AND its series condition (SxxExx-anchored) at the same time — impossible for any real title. Both are now optional, which Radarr treats as either-or. The format is not yet scored in any profile, so this changes no current scoring; it makes the format usable.

Movie DUBBED required · TV DUBBED required  (AND — unsatisfiable)
Movie DUBBED optional · TV DUBBED optional  (OR — either form fires)

OP 216

CAM

cam releases escaped the banv2 only · new in v2

Changed 2026-08-06 18:05 UTC · op 216

Underscore-separated names defeat regex word boundaries (underscore is a word character), so neither the year anchor nor the CAM token could fire — real cams slipped past a −999999 ban. Verified against Radarr source: custom formats match the raw title, underscores intact. Boundaries now accept underscores as separators.

(?<=\b[12]\d{3}\b).*(\b(CAM[ ._-]?(Rip)?|DVD[ ._-]?(SCR(EENER)?)|HD[ ._-]?(CAM|SCR|TC|TS)|SCREENER|TELE(CINE|SYNC)|WORKPRINT)\b)
(?<=(\b|_)[12]\d{3}(\b|_)).*((\b|_)(CAM[ ._-]?(Rip)?|DVD[ ._-]?(SCR(EENER)?)|HD[ ._-]?(CAM|SCR|TC|TS)|SCREENER|TELE(CINE|SYNC)|WORKPRINT)(\b|_))

OP 212

Remux

fed a wrongful Full Disc banv2 only · regression (v1 matched BDRemux)

Changed 2026-08-06 14:55 UTC · op 212

\b(Remux)\b never matched the joined spellings used by Russian and Spanish trackers. This regex is the “Not Remux” gate in 49 formats — worst case, a BDRemux with an AVC tag fired the Full Disc format’s −999999 ban in every profile, and joined-spelling remuxes escaped the Remux and Banned Remux formats entirely.

\b(Remux)\b
\b((BD|UHD)[-_. ]?)?Remux\b

OP 211

Dolby Vision (Without Fallback)

was banning legit releasesbug in v1 + v2

Changed 2026-08-06 13:25 UTC · op 211

The negation list only knew the spelling BLURAY, so hyphenated Blu-ray disc releases — which always carry an HDR10 base layer — were treated as fallback-less DV and hard-banned in 7 profiles. Same fix the project itself made for its UHD Blu-ray regex in PR #31.

(?<=^(?!.*(HDR|HULU|REMUX|BLURAY)).*?)\b(DV|Dovi|Dolby[ .]?Vision)\b
(?<=^(?!.*(HDR|HULU|REMUX|BLU[-]?RAY)).*?)\b(DV|Dovi|Dolby[ .]?Vision)\b
